# شوشع فايتر — Mortal Kombat جزائري 🏆

لعبة قتال (fighting game)inspired بـ Mortal Kombat، بطابع جزائري 100%:
شخصية وحدة قابلة للتحكم هي **حسين شوشع** — أسطورة كرة القدم الجزائرية.

> ⚽️ شوشع ضد شوشع — مرآة! الخصم هو شوشع آخر (CPU) يلقاك بالأسسوأ.

## 🎮 كيفاش تلعب

ال اللعبة HTML/JS خفيفة — مايحتاجش أي تنصيب:

- **ف GitHub Pages**: افتح الريبو → **Settings → Pages** → اختر `main` + `/ (root)` → احفظ.
  بعدها الرابط يولي: `https://anis20110827-cyber.github.io/chouchou-fighter/`
- **محلياً**: نزّل `index.html` + `game.js` + `assets.js` + مجلد `assets-parts/` فواحد،
  وافتح `index.html` فالمتصفح.

على الهاتف كاين **أزرار لمس** (يمين/يسار/نطير/لكم/رفسة/رابونا/صدّ).

## ⚔️ الضربات

كل ضربة عندها **knockback** (تبعثر الخصم بعيداً)، **hitstop** (توقف لحظي عند
الاصطدام)، و**sparks** (شرارات). كاين **combo counter** (HITS) بحال Mortal Kombat.

| الضربة | قوة | ملاحظة |
|---|---|---|
| لكمة (`J`) | 6 | سريعة، تبني الكومبو |
| رفسة (`K`) | 10 | أبعد knockback |
| رابونا (`L`) | 15 | رابونا جوية، تشدّع الخصم |
| صدّ (`S`) | — | يصدّ اللكم والرفسة (ما يصدّش الرابونا) |

## ⌨️ التحكم

| المفتاح | الفعل |
|---|---|
| `A` / `D` (أو `←` / `→`) | تحرّك |
| `W` (أو `↑`) | نطير |
| `S` (أو `↓`) | صدّ |
| `J` | لكمة سريعة |
| `K` | رفسة قوية |
| `L` | **رابونا** (تحتاج طاقة) |
| `Q` / `E` + اتجاه | dash سريع |
| `R` | إعادة الجولة |
| `Esc` | وقفة / رجوع |

## 🛠️ البناء

اللعبة ملف واحد + assets.js (base64). مايحتاجش build step.

```
index.html      # الواجهة + HUD
game.js         # منطق القتال والذكاء الاصطناعي
assets.js       # الصور مضمّنة base64 (تولّد بـ tools/build_assets.ps1)
```

## ⚒️ أدوات التوليد (PowerShell)

- `tools/slice3.ps1` — تقطيع sprite sheet + chroma key ماجنتا
- `tools/optimize2.ps1` — تصغير sprites + إزالة الظل
- `tools/build_assets.ps1` — توليد `assets.js`
